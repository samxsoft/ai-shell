# 交互式 AI 系统维护工具箱 (AI-Shell / Ops Copilot) 需求与架构设计分析

## 1. 项目定位与核心价值

### 1.1 核心定位
面向**普通电脑用户**及**中小型团队**的**可视化桌面端 (GUI) 智能系统维护与排障助手**。
将传统“复杂命令行组合 $\rightarrow$ 逐行阅读晦涩日志 $\rightarrow$ 难以理解的技术参数”彻底简化为**“一句话自然语言提问 $\rightarrow$ AI 自动调用探针检测 $\rightarrow$ 生成通俗诊断报告 $\rightarrow$ 一键可视化确认修复”**的全新体验。

### 1.2 核心价值
- **零技术门槛**：普通用户只需像聊天一样提问（“电脑好卡怎么办”、“C盘变红了”、“连不上网”），无需记忆任何命令。
- **直观易懂的可视化呈现**：技术指标转化为直观的健康分、彩色仪表盘、状态灯与通俗解释，隐藏晦涩的底层日志（支持按需展开）。
- **安全可控的一键修复**：所有处置方案以直观的操作卡片呈现，明确标注安全等级与预计释放资源，用户点击“一键优化/修复”按钮即可完成。
- **开箱即用的独立桌面应用**：提供免安装或一键安装包（Windows `.exe` / macOS `.dmg` / Linux），双击即用。

## 2. 典型场景与交互用例 (面向普通用户)

```mermaid
graph TD
    User([用户在 GUI 界面提问 / 点击快捷诊断卡片]) --> Agent[AI Agent 调度中枢]
    Agent --> Plan[自动规划排查路径]
    Plan --> ReadTools[后台静默运行安全探针 (psutil/系统API)]
    ReadTools --> LLM[LLM 通俗化翻译 & 根因分析]
    LLM --> CardGen[生成可视化处置卡片]
    CardGen --> GUI([GUI 界面呈现诊断结果 & 修复卡片])
    GUI --> UserConfirm{用户点击 [一键优化/修复] 按钮}
    UserConfirm -- 授权执行 --> Action[执行系统清理/修复动作]
    Action --> Refresh[实时更新仪表盘 & 提示完成]
```

| :--- | :--- | :--- | :--- |

### 3.1 核心交互亮点
1. **智能卡片流 (Interactive Action Cards)**：
   - AI 的回答不仅仅是纯文本，而是内嵌可直接点击的**操作卡片**（包含进度条、影响说明、操作按钮）。
2. **渐进式技术详情 (Progressive Disclosure)**：
   - 默认向普通用户展示通俗结论和建议。
   - 提供“**查看详细技术日志**”折叠面板，点击后可展开具体的 CPU 指标、PID 列表或网络 Ping 包延迟（满足进阶用户/技术人员需求）。
3. **安全确认弹窗 (Safety Modals)**：
   - 涉及关停重要进程或删除较多文件时，弹出清晰友好的确认对话框，告知可能影响（如：“该操作将关闭未保存的文档，是否继续？”）。

## 4. 技术架构与选型方案 (GUI 路线)

为满足**普通用户免复杂配置、界面现代美观、系统调用高效**的要求，提供以下两种推荐技术方案：

### 方案 A：Tauri (Rust 后端) + Vue 3 / React + Python 侧载 (推荐 ⭐⭐⭐⭐⭐)
- **前端 UI**：Vue 3 / React + Tailwind CSS / Element Plus / DaisyUI（极致精美的现代界面，支持深浅色模式与流畅动画）。
- **宿主框架**：Tauri 2.0（基于系统原生 Webview，打包体积仅 **10~15MB**，内存占用不到 30MB）。
- **系统探针与执行**：Rust 原生系统 API（`sysinfo` 库）极速读取性能指标，或调用 Python 运维引擎脚本。
- **优点**：体积极小、启动毫秒级、UI 极度现代奢华、跨平台打包极佳（支持生成 Windows `.msi`/`.exe`、macOS `.dmg`）。

### 方案 B：PySide6 (Qt for Python) 桌面客户端 (推荐 ⭐⭐⭐⭐)
- **GUI 框架**：PySide6 + `PyQtDarkTheme` / `QMaterialWidgets` / `PyQt-Fluent-Widgets`（提供 Windows 11 Fluent 现代风格）。
- **核心逻辑**：纯 Python 实现，直接集成 `psutil`、`subprocess`、`openai` / `litellm` SDK。
- **打包工具**：PyInstaller 或 Nuitka 打包为单文件 `.exe`。
- **优点**：全 Python 技术栈，无需学习前端与 Rust，开发与调试最快。

### 方案 C：本地轻量 WebUI (FastAPI + Web 前端 + 自动拉起浏览器/PWA)
- **后端**：FastAPI 提供 WebSocket / Server-Sent Events (SSE) 流式传输。
- **前端**：现代 Web 单页应用，支持桌面快捷方式启动。

## 5. 系统安全防护与权限设计

1. **权限请求最小化与 UAC 引导**：
   - 基础诊断操作无需管理员权限（普通用户权限运行）。
   - 仅当执行深度清理、重启特定系统服务、配置网络适配器等高权限操作时，才按需触发 Windows UAC 提权弹窗，避免开机强制要求管理员权限吓退用户。
2. **高危操作沙箱与黑名单**：
   - 严格禁止 AI 执行格式化盘符、删除系统核心目录（`C:\Windows`、`/usr`）、清空网络路由表等破坏性指令。
3. **操作还原与快照机制**：
   - 自启项禁用支持“一键还原”。
   - 清理文件默认优先移入系统回收站，或在专用临时隔离区保留 24 小时后再彻底粉碎。

## 6. 实施路线图规划 (Roadmap)

1. **Phase 1 (GUI 原型与核心对话体验)**：
   - 搭建现代 GUI 桌面主界面（仪表盘 + 智能对话窗）。
   - 实现 LLM 流式对话与 Tool Call 联动机制。
   - 完成 3 大核心场景：电脑卡顿分析、C盘垃圾扫描、网络连通性一键诊断。
2. **Phase 2 (交互式操作卡片与一键修复)**：
   - 实现可交互的 Action Cards（一键杀卡死进程、一键清理缓存、一键重置 DNS）。
   - 增加图形化“快捷工具箱”磁贴列表。
   - 支持多模型配置切换面板（支持 DeepSeek、OpenAI、本地 Ollama 自动检测）。
3. **Phase 3 (桌面端打包与高级体验)**：
   - 打包发布 Windows/macOS 独立安装包。
   - 增加悬浮窗/托盘常驻模式与异常状态主动气泡提醒。
